# Create: Powertrain

Create: Powertrain adds practical blocks for building machines in the **Sable** physics environment. Its goal is to give builders more useful ways to connect, control, and work with moving structures.

## Dependencies

Built for **Minecraft 1.21.1** with **NeoForge 21.1.228 or later**.

Requires **Create 6.0.10 or later within the 6.0.x series**, **Sable 2.0.0+**, **Synaxis 1.4.0+**, **Sable Schematic API 0.4.0+**, and **Aeronautics 1.3.0+**, which provides the Simulated systems used by the mod. Install the dependencies required by those mods as well.

Optional integrations support **Jade 15.x** on the client and **Tracks 1.0.0+**.
